## Legacy Material

This directory holds superseded scripts, logs, and planning notes from earlier
Example 5 runs. The canonical calibration is **Run 13** (MAD ensemble +
ETo-corrected); see `RUN13_REFERENCE.md` in the example root.

| File | Origin |
|------|--------|
| `RUN11_REFERENCE.md` | Superseded Run 11 reference (simple ensemble mean, no ETo correction) |
| `evaluate_run12.py` | Run 12 evaluation wrapper (ETo-corrected, no MAD) |
| `copy_openet_assets.py` | Abandoned personal-asset copy approach (EE quota exceeded) |
| `PstFrom.log` | PestBuilder build log from last calibration run |
| `openet_etf_assets.txt` | Asset inventory for the abandoned copy workflow |
| `reextract_stale_data.py` | One-off helper to re-extract stale EE data |
| `cache/`, `generated/`, `logs/` | Build artifacts from prior calibration runs |
| `notes/` | Historical planning and investigation notes |
